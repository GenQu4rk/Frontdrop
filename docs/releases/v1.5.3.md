# Frontdrop 1.5.3

Download **Frontdrop-1.5.3-arm64.dmg** below. Open it, drag **Frontdrop.app** to **Applications**, then eject the image and open the app. Quit an existing copy before updating. Existing wallpaper libraries are retained.

## Fixes

- Removing an imported video now saves the library before deleting media. If the metadata write fails, the video, favourite and playback state remain intact.
- A one-favourite rotation resets its interval instead of reapplying the same wallpaper every three seconds.
- Returning to the source directory keeps retained provider videos paused.
- Repeated browser hide/show events no longer stack WebKit suspensions or leave visible previews stuck.

## Requirements and verification

- Apple silicon (arm64), macOS 14 or later. Runtime checks were performed on Apple silicon with macOS 26.6.2; older macOS versions and Intel runtime behaviour have not been verified.
- This community build is ad-hoc signed and **not notarized by Apple**. If macOS blocks it, review [Apple's downloaded-app guidance](https://support.apple.com/en-gb/102445).
- Download the `.sha256` file alongside the DMG and run:

  ```sh
  shasum -a 256 -c Frontdrop-1.5.3-arm64.dmg.sha256
  ```

Source builds and the repeatable DMG packaging script are included in the repository. Wallpaper-provider pages require internet; bundled scenes and imported videos work offline.
