## What’s new

- Add MP4 or MOV files from a prominent **Add your own MP4** button, the toolbar, or by dropping files onto the app window. The macOS file picker can select several videos at once.
- Name each wallpaper while importing. Frontdrop suggests the filename and saves the chosen name with the managed video copy.
- Check for updates in **Settings → Frontdrop**. When a compatible newer DMG is available, open its GitHub release page to download it.

Frontdrop 1.6.0 requires macOS 14 or later. This release contains an Apple silicon DMG and its SHA-256 checksum. Quit Frontdrop before dragging the new app into Applications. The community build is ad-hoc signed and is not notarized by Apple.
