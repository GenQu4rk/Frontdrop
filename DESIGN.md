# Frontdrop design

Native macOS media library: system typography, SF Symbols, standard titlebar, source sidebar, keyboard-accessible controls. Dark canvas lets wallpaper artwork carry the colour; no decorative app gradients. Artwork previews use actual renderer output. Large selected scene at left and a compact control inspector at right; a thumbnail library below supports discovery. Controls: select, preview, apply; selected and applied states are distinct. User can always stop wallpaper playback and return to the existing macOS wallpaper.

Gallery cards are image-only media thumbnails with title and a favourite button, not generic feature cards. Muted sage accent. Window minimum 920 × 660. Wallpaper shaders provide authored smooth motion; native UI honours system focus and reduced motion.

The default library window is 1120 × 820. Both NavigationSplitView column stacks are explicitly constrained to the GeometryReader's available content height. Keep the sidebar footer and the playback status/Stop bar outside their scrolling collections and visible at the bottom. Outer split-view framing alone does not reliably constrain column hosts on the tested macOS version. The minimum window is 920 × 660; only the default size was visually reviewed in this session.

Brand mark: user-supplied purple twin-ribbon F on charcoal, from the Canva export retained in FrontdropLogo.png. Use the revised Canva artwork for the Dock icon. The sidebar uses FrontdropLogoTransparent.png with genuine alpha and no tile or clipping; the menu bar uses a monochrome template rendered from this revised silhouette. The rest of the app retains its existing sage controls and native styling. `scripts/build.sh` regenerates every icon size from the canonical artwork.

Closing the last library/settings window changes activation policy to accessory: wallpaper playback and the menu-bar item continue, while the app leaves the Dock. Open Frontdrop from the menu bar restores a regular app and the library window. Desktop wallpaper windows never count as user windows.

Discover has eleven collection shortcuts: Anime, Gaming, Space, Nature, Fantasy, Movies & TV, Animals, City & landscapes, Cars, Abstract and Cyberpunk. The source picker and sidebar selection remain synchronized. Discover and local Library share a scrolling native sidebar list; branding and help footer stay outside the scroll area.

Browse includes a small Block ads switch at the trailing edge of the provider information strip. Blocking is on by default and retained locally. Changing it reloads the committed page; targeted content rules are installed before initial navigation, while wallpaper thumbnails, previews, downloads and source credits remain part of the live provider page.

Discover collections share a separate provider picker (LiveWallpapers4Free/MotionBGS/DesktopHut). Anime/Gaming expose compact native series/game menus; title searches cover the selected provider without adding category keywords. Native pagination lives below the provider web view and follows that page's actual next/previous links. Closing with X hides and preserves the library scene, browser history and scroll positions. Local selection uses one stable preview host, showing its thumbnail immediately while media prepares asynchronously; hidden/occluded previews pause.

Browse starts at a native source directory. Three integrated video libraries are listed before the external Steam Workshop and Backdrop references, whose access and format limits are visible. Each row names a real source and action; no combined collection size is claimed. All source results stay on credited provider pages. Searches retain the same term when switching providers. Full-motion preference is explicit guidance to preview the actual motion; no unverified universal motion filter is claimed. Sakugabooru and Mixkit were removed from discovery following user feedback. Previously imported videos remain available, including the local Scenes filter.

Some providers deliver a desktop video inside a ZIP. Only a single supported video is streamed from the archive to a managed UUID filename; archive paths and executable contents are never extracted. Workshop Video import accepts one user-selected project folder, preserves its manifest title/attribution, and rejects interactive project formats.

Video framing: every imported/downloaded video defaults to Fit whole video, including legacy records without a framing field. A native picker in the selected-video inspector offers Fit whole video / Fill screen, with explicit black-bar/cropping help. The choice is per wallpaper. Preview and desktop update their existing AVPlayerLayer gravity without recreating players; shaders remain unchanged.

Wallpaper storage: Settings displays the actual selectable library path above Show video library in Finder. This Mac uses `/Volumes/MicroSD/Frontdrop/Library`; videos, download/archive staging and library metadata share that root. Validate the configured mounted volume UUID before reading/writing and after asynchronous imports; unavailable storage must show an error without silently creating a library on another drive. Commit imported metadata before announcing success.
